# Alfanar Projects marketing assessment

Independent candidate assessment. Open `index.html` in a modern browser. No build, packages, tracking or API keys required. Images load from official Alfanar URLs.

## Controls

- Arrow keys / Space: navigate
- F: full screen
- N: speaker notes, with timer and slide controls
- O: overview
- Home / End: first / last slide
- Print / PDF: all 12 slides in 16:9; use landscape and background graphics
- Reading copy: scrolling slides with notes

The notes cover a 20-minute speaking plan including pauses. Mobile uses a readable stacked layout.
